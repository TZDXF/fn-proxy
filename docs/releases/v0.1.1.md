# FN Proxy v0.1.1

本版本改进代理启动、NAS 会话恢复与服务管理，提供 Windows x64 桌面安装包。

## 新增与改进

- 新增“启动时自动开启代理”设置：打开应用后，使用已保存的凭据连接 NAS 并启动已启用的服务映射；此选项不是系统开机自启。
- 重新整理设置页，将代理与通用设置分组，优化局域网访问提示。
- 支持代理运行中编辑服务映射，并增量调整端口监听。
- 优化 NAS 自动连接与服务发现，静默加载发现结果并标注注册表来源。
- 新增运行日志文件持久化与有界轮转，便于排查问题。
- 后端消息统一通过前端语言资源显示，完善中英文提示。

## 修复

- 改进 NAS 会话过期与撤销后的自动重新认证，并限制恢复重试次数。
- 简化连接与代理操作，完善过期代理凭据、跨站导航和工作区状态的回归测试。
- 规范发布附件名称，确保安装包名称与校验文件一致。

## 下载与安装

下载 Releases 附件中的 Windows x64 setup.exe 安装包，使用 SHA256SUMS.txt 校验文件完整性。

安装包未进行 Windows 代码签名，可能出现 SmartScreen 提示；请确认下载来源与校验值。需要 WebView2 Runtime，安装器会按需引导安装。更新仍需手动下载安装。

## 安全与兼容性

密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。自动开启代理需要已保存的凭据及已启用的服务映射。

默认仅监听 127.0.0.1。局域网访问须显式开启，入口没有额外密码，访问者共用 NAS 会话凭据；仅限可信网络，切勿暴露到公网。

真实 NAS 环境、窗口、托盘与局域网交互仍需在实际设备上验证。
