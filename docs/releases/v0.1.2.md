# FN Proxy v0.1.2

本版本新增开机自启、NAS 主入口映射与版本更新检查改进，提供 Windows x64 桌面安装包。

## 新增与改进

- 新增“开机自启”设置：登录系统后自动打开 FN Proxy；代理是否自动开启仍由“启动时自动开启代理”设置单独控制。
- 新增“NAS 主入口”服务映射预设：通过 `https://{FNID}.fnos.net/` 代理 NAS 主域名，保留请求路径与查询参数，支持 HTTP 与 WebSocket（含 `/websocket?type=main`），默认本地端口 18000，占用时自动顺延。
- 更新检查共享单一实例，设置页与界面其他位置状态一致；版本标签动态显示当前应用版本。

## 下载与安装

下载 Releases 附件中的 Windows x64 setup.exe 安装包，使用 SHA256SUMS.txt 校验文件完整性。

安装包未进行 Windows 代码签名，可能出现 SmartScreen 提示；请确认下载来源与校验值。需要 WebView2 Runtime，安装器会按需引导安装。更新仍需手动下载安装。

## 安全与兼容性

密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。主入口映射严格限定为当前连接的 FN ID，保持 HTTPS、凭据、端口及根地址校验；不会代理跳往其他域名的应用入口，也不会将应用内的 NAS 登录状态自动传入浏览器。

默认仅监听 127.0.0.1。局域网访问须显式开启，入口没有额外密码，访问者共用 NAS 会话凭据；仅限可信网络，切勿暴露到公网。

真实 NAS 环境、窗口、托盘与局域网交互仍需在实际设备上验证。
