# FN Proxy v0.1.0

首个公开版本，提供 Windows x64 桌面安装包。

## 功能

- 多 NAS 连接、会话认证与可选本机凭据保存。
- 服务发现与映射、HTTP / WebSocket 本机反向代理。
- Docker 服务端口发现与映射。
- 系统托盘、自定义标题栏、中英文界面及明暗主题。
- 默认仅监听 127.0.0.1；可在设置中显式开启可信局域网访问。
- 设置页展示当前版本，并可检查 GitHub 最新正式版本及打开下载页。

## 下载与安装

下载 Releases 附件中的 Windows x64 setup.exe 安装包。SHA256SUMS.txt 提供安装包校验值。

本版本未进行 Windows 代码签名，安装时可能出现 SmartScreen 提示；请确认下载来源与校验值。需要 WebView2 Runtime，安装器会按需引导安装。

## 更新与安全说明

更新检查仅访问本仓库的 GitHub Releases API，不发送 NAS 密码、Cookie 或 Token。更新需手动下载安装，未启用后台下载或自动安装。

密码通过本机 IPC 进入 Rust；持久化使用 Windows 凭据管理器。局域网监听仅用于可信网络。此版本未完成所有真实 NAS 环境与 Windows 桌面交互的兼容性验证，请先在测试环境使用。
