# FN Proxy v0.1.6

本版本新增远程服务可用性检测，将上游服务状态与本地代理监听状态分开展示，并修复 FN Connect 拒绝页面因较长内联样式导致的凭据过期漏检。

## 新增与改进

- 服务映射列表与服务发现列表新增远程状态提示，区分未认证、无权限、地址不存在、检测超时和无法连接等情况，避免将本地端口正在监听误认为远程服务可用。
- 连接后自动检测远程服务，每 60 秒刷新一次，并提供手动重新检测入口；最多并发检测两个地址，相同远程地址复用结果。
- 检测结果按连接会话和远程地址隔离，断开、切换连接或重连后丢弃旧结果，避免过期状态影响当前连接。
- 修复 FN Connect 401/403 拒绝页的权限提示位于较长内联样式之后时无法识别的问题，将有限响应检查范围由 16 KiB 调整为 64 KiB，恢复原有的入口凭据刷新流程。

## 下载与升级

已安装 v0.1.5 的用户可在设置页直接检查并安装更新，也可下载 Releases 附件中的 Windows x64 setup.exe，并使用 SHA256SUMS.txt 校验文件完整性。

应用尚未进行 Authenticode 代码签名，安装时可能出现 Windows SmartScreen 提示；应用内更新包已由独立的 Tauri minisign 密钥签名。需要 WebView2 Runtime，安装器会按需引导安装。

## 安全与兼容性

远程检测仅访问经校验的上游地址，不跟随重定向，界面仅展示经过分类的状态，不泄露凭据、响应正文或底层网络错误详情。拒绝页检查仍受 64 KiB 大小和 2 秒时限约束；无请求体的 GET/HEAD 最多自动重试一次，写请求不自动重放。

更新下载仅访问本仓库 GitHub Releases，并验证发布签名。密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。默认仅监听 127.0.0.1；局域网访问须显式开启，仅限可信网络，切勿暴露到公网。

真实 NAS 授权恢复、安装与升级流程、窗口、托盘、轻量模式及局域网交互仍需在实际设备上验证。
