# FN Proxy v0.1.5

本版本为服务映射加载真实站点图标并缓存，连接中断时显示「重连中」状态，同时修复 FN Connect 权益查询丢失 NAS 登录令牌的问题，并在界面给出具体失败原因。

## 新增与改进

- 服务图标改为从各服务站点实际抓取：自动解析站点 HTML 中的图标声明并回退到 favicon.ico，支持 SVG 图标；抓取前校验上游域名、限制重定向与响应大小，结果在前端缓存，避免重复请求。
- 连接断开并自动恢复时，连接列表与服务映射中显示「重连中」徽标，与彻底断线状态区分。
- 修复 FN Connect 权益查询在票据登录场景下未携带 NAS 登录令牌、导致查询失败的问题；查询失败时界面展示具体原因（认证被拒绝、权限不足、超时、网络错误等），便于定位配置问题。

## 下载与升级

已安装 v0.1.4 的用户可在设置页直接检查并安装更新，也可下载 Releases 附件中的 Windows x64 setup.exe，并使用 SHA256SUMS.txt 校验文件完整性。

应用尚未进行 Authenticode 代码签名，安装时可能出现 Windows SmartScreen 提示；应用内更新包已由独立的 Tauri minisign 密钥签名。需要 WebView2 Runtime，安装器会按需引导安装。

## 安全与兼容性

更新下载仅访问本仓库 GitHub Releases，并验证发布签名。图标抓取仅访问已认证服务的上游域名，失败诊断信息经白名单过滤，不泄露地址或凭据。密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。

默认仅监听 127.0.0.1。局域网访问须显式开启，仅限可信网络，切勿暴露到公网。窗口、托盘、轻量模式与局域网交互仍需在实际设备上验证。
