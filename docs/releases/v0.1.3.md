# FN Proxy v0.1.3

本版本新增签名验证的应用内更新，自动升级时无需手动卸载旧版本，并提供 Windows x64 安装包。

## 新增与改进

- 新增应用内“下载并安装更新”：下载后验证 Tauri updater 签名，显示进度并支持立即重启。
- Windows 更新使用 passive 模式：只显示小型进度窗口，自动完成安装，无需手动卸载旧版本。
- Release 工作流现在生成签名安装包、`latest.json` 更新清单和 SHA256 校验文件；缺少签名私钥时会停止发布，避免发布未签名更新。
- 保留发布页入口，作为应用内更新不可用时的备用下载方式。

## 下载与升级

可从设置页检查并安装更新，也可下载 Releases 附件中的 Windows x64 setup.exe，并使用 SHA256SUMS.txt 校验文件完整性。

包含本版本的安装包仍可能出现 Windows SmartScreen 提示：应用尚未进行 Authenticode 代码签名，但应用内更新包已由独立的 Tauri minisign 密钥签名。需要 WebView2 Runtime，安装器会按需引导安装。当前旧版本没有 updater 插件，升级到本版本需要最后手动安装一次；之后的版本可直接使用应用内更新。

## 安全与兼容性

更新下载仅访问本仓库 GitHub Releases，并验证发布签名；签名私钥只保存在本地安全位置和 GitHub Actions Secret，不进入仓库、日志或配置文件。密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。

默认仅监听 127.0.0.1。局域网访问须显式开启，仅限可信网络，切勿暴露到公网。真实发布包、升级流程、窗口、托盘与局域网交互仍需在实际设备上验证。
