# FN Proxy v0.1.7

本版本改善连接恢复时对短暂入口不稳定的处理，并细化连接失败诊断。

## 修复与改进

- 将自动重连的两次退避间隔调整为 5 秒和 30 秒，以覆盖持续数十秒的入口不稳定情况。
- 区分连接拒绝、连接超时和 TLS 连接失败，帮助定位恢复失败原因；诊断信息仍仅包含安全分类，不记录地址、凭据或证书等敏感详情。

## 下载与升级

已安装 v0.1.6 的用户可在设置页检查并安装更新，也可下载 Releases 附件中的 Windows x64 setup.exe，并使用 SHA256SUMS.txt 校验文件完整性。

应用尚未进行 Authenticode 代码签名，安装时可能出现 Windows SmartScreen 提示；应用内更新包已由独立的 Tauri minisign 密钥签名。需要 WebView2 Runtime，安装器会按需引导安装。

## 安全与兼容性

更新下载仅访问本仓库 GitHub Releases，并验证发布签名。密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。默认仅监听 127.0.0.1；局域网访问须显式开启，仅限可信网络，切勿暴露到公网。

真实 NAS 授权恢复、安装与升级流程、窗口、托盘及局域网交互仍需在实际设备上验证。
