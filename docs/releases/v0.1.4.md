# FN Proxy v0.1.4

本版本新增轻量模式以降低常驻内存占用，改进服务映射的操作入口与图标，并增强上游连接失败后的认证恢复能力。

## 新增与改进

- 新增「轻量模式」（默认关闭）：关闭主窗口时销毁界面及 WebView，释放界面占用的内存；Rust 后端、代理转发、认证续期和托盘继续运行，点击托盘图标可重新打开界面并读取当前运行状态。未保存的界面输入会丢失，重新打开窗口需要短暂加载。
- 服务映射新增服务图标，并为每条映射提供「复制远程地址」「打开本地地址」「打开远程地址」等操作入口。
- 上游连接失败后在后台探测认证状态（30 秒节流，不重放失败的请求），会话失效时自动重新登录恢复；服务发现整体超时或全部来源失败时也会触发认证探测，减少误判断线。

## 下载与升级

已安装 v0.1.3 的用户可在设置页直接检查并安装更新，也可下载 Releases 附件中的 Windows x64 setup.exe，并使用 SHA256SUMS.txt 校验文件完整性。

应用尚未进行 Authenticode 代码签名，安装时可能出现 Windows SmartScreen 提示；应用内更新包已由独立的 Tauri minisign 密钥签名。需要 WebView2 Runtime，安装器会按需引导安装。

## 安全与兼容性

更新下载仅访问本仓库 GitHub Releases，并验证发布签名。密码仍通过本机 IPC 进入 Rust，并使用 Windows 凭据管理器保存。轻量模式只释放界面进程，不影响代理转发与凭据存储。

默认仅监听 127.0.0.1。局域网访问须显式开启，仅限可信网络，切勿暴露到公网。窗口、托盘、轻量模式与局域网交互仍需在实际设备上验证。
